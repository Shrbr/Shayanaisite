  1. Download and extractدانلود و استخراجDownload the ZIP, then extract it to get “Shayan AI.apk”.فایل ZIP را دانلود و باز کن تا «Shayan AI.apk» بیرون بیاید.
  2. Open the APKفایل APK را باز کنTap the file from your Files app or downloads.از برنامه‌ی فایل‌ها یا دانلودها روی آن بزن.

  5. Open and connectباز کن و وصل کنOpen Shayan AI and connect your API.Shayan AI را باز کن و API خودت را وصل کن.
  1. Download and extract allدانلود و استخراج کاملRight-click the ZIP and choose Extract All. Don’t run files from inside the ZIP.روی ZIP راست‌کلیک و Extract All را بزن. فایل‌ها را از داخل ZIP اجرا نکن.

Which devices are supported?روی چه دستگاه‌هایی کار می‌کند؟

Android (APK), Windows (installer package), and any modern browser — including iPhone — through the web app.اندروید (فایل APK)، ویندوز (بسته‌ی نصب) و هر مرورگر امروزی، از جمله آیفون، از طریق نسخه‌ی وب.

Do I need an API key?به کلید API نیاز دارم؟

API mode connects to your own API (OpenAI, OpenRouter, Groq or Anthropic). Local mode needs no API but needs a device with WebGPU.حالت API به API خودت وصل می‌شود (OpenAI، OpenRouter، Groq یا Anthropic). حالت محلی به API نیاز ندارد ولی دستگاهی با WebGPU می‌خواهد.

Does it support Persian?فارسی پشتیبانی می‌شود؟

Yes — Persian and English, with full right-to-left layout.بله، فارسی و انگلیسی با چیدمان کامل راست‌به‌چپ.

Android blocks the install.اندروید نصب را مسدود می‌کند.

Allow installing apps from this source in Settings. If Play Protect warns you, choose “Install anyway”.در تنظیمات اجازه‌ی نصب از این منبع را بده. اگر Play Protect هشدار داد، «Install anyway» را بزن.

Windows shows a warning.ویندوز هشدار می‌دهد.

Windows may warn about an unknown publisher. Use “Run with PowerShell”, or open the web app instead.ممکن است ویندوز درباره‌ی ناشر ناشناس هشدار بدهد. «Run with PowerShell» را بزن یا از نسخه‌ی وب استفاده کن.
